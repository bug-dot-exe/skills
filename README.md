# Plamen Audit Skills

Security auditing skills for the Plamen Web3 security auditing pipeline.

## Structure

- `evm/` — EVM/Solidity skills (18 skills)
- `solana/` — Solana/Anchor skills (20 skills)
- `aptos/` — Aptos Move skills (22 skills)
- `sui/` — Sui Move skills (22 skills)
- `injectable/` — Protocol-type-specific injectable skills (8 skills)
- `niche/` — Flag-triggered standalone niche agent skills (8 skills)

## Usage

Each skill is defined in its `SKILL.md` file and is loaded by audit agents during the Plamen pipeline based on trigger patterns detected during recon.
